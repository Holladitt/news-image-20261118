# The Day in World News — Wednesday 18 November 2026

Entry for the [make.fun](https://make.fun) bounty
`news-image-20261118`: sum up 18 November 2026's world news in one image.

The program draws a dense front page — masthead, three hero stories,
a ten-panel grid, a world map with numbered pins and an "Also on"
list — covering 31 stories from six continents, all of them reported
on Wednesday 18 November 2026. Every illustration is drawn
procedurally with Pillow; no network, no external assets.

## Run

```sh
python3 main.py
# writes /output/entry.png (1024x1024, deterministic)
```

Requires Python 3.13 and Pillow (`pip install pillow`).
